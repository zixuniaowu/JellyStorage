# 果冻拼装乱斗 — 项目说明 & 想法征集

> 版本：概念 / 可玩原型（Android）  
> 包名：`com.jellystorage`  
> 目的：请帮忙从「好玩、好传播、能上架」角度提想法与拍板建议

---

## 1. 一句话是什么

**给果冻怪拼装最多 3 件带标签的武器 → 标签凑对触发「奇妙组合」→ 在擂台上和 AI 怪物自动对打 → 每关有克制，装错打不动、装对才通关。**

类型关键词：  
`拼装 / 构筑` · `属性组合 / 协同` · `PVE 关卡` · `自动战斗演出` · `软萌果冻视觉`

---

## 2. 我们想解决的「乐趣点」

| 想给的爽点 | 设计意图 |
|------------|----------|
| **拼装发现感** | 「火+冰=蒸汽爆」这种组合惊喜 |
| **关卡谜题感** | 不是纯数值碾压，要对上克制/指定协同 |
| **战斗可看性** | 弹幕、飘字、连击、K.O.，不是纯日志 |
| **短循环** | 拼装 30 秒 → 打 20～40 秒 → 过关/重配 |
| **软萌差异化** | 软体果冻造型，区别于硬核机甲/卡牌 UI |

## 3. 当前玩法结构（已实现原型）

### 3.1 流程
```
标题页
  → 征程地图（8 关，通关解锁）
    → 拼装工坊（最多 3 武器）
      → 战场（自动战斗 + 演出）
        → 胜利 / 失败
          → 下一关拼装 or 回地图
```

### 3.2 拼装
- 武器有 **标签**：火 / 冰 / 雷 / 毒 / 盾 / 穿 / 爆 / 吸 / 迅 / 重  
- 最多装备 **3 件**  
- 标签凑齐协同条件 → 激活 **奇妙组合**（加攻防、弹幕数量、灼烧、吸血、反伤、暴击等）  
- 关卡提示会告诉玩家大概要往哪个方向凑  

### 3.3 战斗
- 双方软体怪站在擂台两侧  
- 按武器样式发射不同弹幕（火球、冰刺、毒雾等）  
- 飘字伤害 / 暴击 / 吸血 / 反伤、受击挤压、屏幕震动、COMBO、K.O.  
- **装错指定协同**：输出被大幅压制（防「随便装也能过」）  

### 3.4 关卡示例（当前 8 关）

| 关 | 敌人 | 设计意图（克制） |
|----|------|------------------|
| 1 | 泥浆史莱姆 | 教学：带【火】即可 |
| 2 | 熔岩甲虫 | 【冰】+【重】→ 碎冰重击 |
| 3 | 毒沼幽灵 | 【雷】+【盾】→ 雷甲反伤 |
| 4 | 冰原巨齿 | 【火】+【冰】→ 蒸汽爆裂 |
| 5 | 瘟疫母体 | 【毒】+【吸】→ 瘟疫吸血 |
| 6 | 雷暴傀儡 | 【穿】+【迅】→ 连锁钻击 |
| 7 | 爆裂孢囊 | 燃毒 or 熔火 |
| 8 | 混沌胶皇 Boss | 蒸汽爆 / 碎冰 等顶级组合 |

### 3.5 技术现状
- Android / Kotlin / Jetpack Compose Canvas  
- 无商业引擎，软体外观为程序化多边形  
- 本地存档进度；震动有，音效资源可选  
- 状态：**可玩原型**，未达到商店完整上架品质

## 4. 已知问题 / 不够好的地方（请狠批）

1. **战斗偏自动**：玩家不能实时操作，观感容易「看戏」  
2. **拼装深度有限**：武器约 12、协同约 10，后期可能重复  
3. **视觉仍偏原型**：缺少立绘、场景层次、技能全屏演出  
4. **失败反馈**：主要靠压制伤害 + 文案提示，缺「差一点就对了」的引导  
5. **命名与幻想**：项目曾叫 JellyStorage（收纳），中间试过弹射闯关，现定拼装对战——**产品身份还不稳**  
6. **变现/留存未设计**：无每日、无赛季、无广告点、无社交  

---

## 5. 历史尝试（避免重复踩坑）

| 方向 | 结果 |
|------|------|
| 软体果冻「塞进箱子」收纳 | 操作拧巴、无关卡感、不好玩 |
| Vampire Survivors 式清怪 | 软体变皮、差异化弱 |
| 弹射进洞闯关（高尔夫/弹弓） | 手感与关卡量要求高，当前完成度不够 |
| 纯文字自动战 | **被否**：无过场/无演出，太简陋 |
| **现版：拼装 + 标签协同 + 可视化自动战** | 方向更贴需求，但深度与演出仍要加 |

## 7. 可发散的方向灵感（抛砖引玉）

1. **拼装不是菜单点选**，而是把零件「砸」到果冻身上，物理吸附（发挥软体）  
2. **组合成功有过场动画**（蒸汽爆 = 全屏白汽；碎冰 = 冰块碎裂）  
3. **敌人也会拼装**，可见它的 3 件装备，倒推克制  
4. **残局二阶段 Boss**：血一半换装，逼玩家改配  
5. **观战分享**：结算生成「本场组合卡片」图，方便发社交媒体  
6. **双人本地**：一人拼装 vs 另一人拼装  
7. **Roguelike 一局**：每关三选一武器，死了重来，而不是固定 8 关地图
