## 本机游戏数据

本游戏会在设备本地保存本机档案名称、口令、角色、游戏进度、设置、金币、战斗统计和最近一次崩溃摘要。这些数据用于恢复游戏进度和诊断本机问题，不会由开发者服务器接收，也不提供云同步。卸载应用或清除应用数据会删除这些内容。

## 广告与第三方服务

本游戏使用 Google Mobile Ads SDK（AdMob）展示插页式广告和由玩家主动选择的激励广告，并使用 Google User Messaging Platform（UMP）管理适用地区的隐私选择。

Google Mobile Ads SDK 可能为广告投放、分析和防范欺诈收集或共享：IP 地址（可能推断大致位置）、应用交互、诊断信息、广告 ID、App Set ID 及其他适用的设备或账号标识符。传输过程使用加密连接。具体处理方式以 Google 的隐私政策及广告技术说明为准。

玩家可通过游戏“记录 / 设置 → 广告隐私选项”修改适用的广告隐私选择，也可以在 Android 系统设置中重置或删除广告 ID。

## 崩溃与性能信息

游戏会在应用私有目录保存最近一次崩溃摘要。Google Play 还可能通过 Play Vitals 向开发者提供聚合的崩溃、卡顿和性能信息。

# ゼリー勇者 プライバシーポリシー（公開前テンプレート）

> 公開前に角括弧内を置き換え、このページを一般公開された HTTPS URL に配置してください。

施行日：[YYYY-MM-DD]

開発者：[開発者名または法人名] は、「ゼリー勇者」（以下「本ゲーム」）を提供します。

## 端末内のゲームデータ

本ゲームは、端末内のプロフィール名、パスワード、キャラクター、ゲーム進行、設定、金貨、戦闘統計、直近のクラッシュ概要を端末内に保存します。これらはゲーム進行の復元および端末上の問題の診断に使用され、開発者のサーバーには送信されません。クラウド同期機能もありません。アプリのアンインストールまたはアプリデータの消去により削除されます。

## 広告および第三者サービス

本ゲームは、インタースティシャル広告とプレイヤーが任意で選択するリワード広告を表示するために Google Mobile Ads SDK（AdMob）を使用し、該当地域のプライバシー設定を管理するために Google User Messaging Platform（UMP）を使用します。

Google Mobile Ads SDK は、広告配信、分析、不正防止のため、IP アドレス（おおよその位置情報の推定に利用される場合があります）、アプリでの操作、診断情報、広告 ID、App Set ID、その他該当する端末またはアカウント識別子を収集または共有する場合があります。通信には暗号化された接続が使用されます。詳細は Google のプライバシーポリシーおよび広告技術に関する説明をご確認ください。

プレイヤーは、ゲーム内の「記録・設定 → 広告プライバシー設定」から、該当する広告プライバシー設定を変更できます。また、Android のシステム設定から広告 ID をリセットまたは削除できます。

## クラッシュおよびパフォーマンス情報

本ゲームは、アプリ専用領域に直近のクラッシュ概要を保存します。Google Play は、Play Vitals を通じて、集計されたクラッシュ、応答停止、パフォーマンス情報を開発者に提供する場合があります。

本ゲームの対象年齢は：[実際の対象年齢を記入] です。子どもを対象ユーザーに含める場合は、公開前に Google Play のファミリーポリシー、広告設定、および本ポリシーの内容を改めて確認してください。

端末内データは、プレイヤーがシステム設定からアプリデータを消去するか、本ゲームをアンインストールするまで保持されます。広告関連データは Google のポリシーに従って処理されます。プライバシーに関するお問い合わせは、下記までご連絡ください。
