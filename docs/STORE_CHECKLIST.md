## 你必须完成（否则无法上架 / 无收益）

1. **正式签名**
   - 生成 upload keystore，配置 `signingConfigs.release`
   - 上传 **AAB** 到 Play Console

2. **AdMob 正式 ID**（当前是测试广告）
   - `AdConfig.kt`：`USE_TEST_ADS = false`，填 `PROD_*`
   - `AndroidManifest.xml` 的 `APPLICATION_ID` 换成你的 `ca-app-pub-xxx~yyy`
   - 切勿带着 Google 测试 ID 上架

3. **隐私政策 URL**
   - 公开网页说明：本地存档、广告 SDK、无强制服务器账号
   - Play「应用内容 → 隐私政策」填入

4. **Data safety / 广告标识符**
   - 声明 AdMob 收集项；欧盟等区域建议接 UMP 同意弹窗

5. **商店素材**
   - 512 图标、功能图、手机横屏截图 ≥2、简短与完整说明
   - 内容分级问卷

6. **音效资源（强烈建议再发一版）**
   - `res/raw/` 放入短音效后接 `soundOn`（当前开关已预留）

## 产品诚实说明（评分相关）

- **账号是本机存档**，不是云账号；文案勿写「云同步 / 跨设备登录」
- 横屏动作 Roguelite，适合手机横握；平板可再优化安全区
- 上架后优先看：崩溃率、误触清档投诉、广告频率投诉
