# 果冻勇者（Jelly Heroes）— 当前内容总结

> 版本：**v1.2.0-gear-class**  
> 包名：`com.jellystorage`  
> 入口：`PlayScreen`（由 `softbody/GameView.kt` 调起）  
> 横屏操作 · Kotlin + Jetpack Compose Canvas · 无物理引擎  
> 构建：`gradlew assembleDebug` → `adb install -r app/build/outputs/apk/debug/app-debug.apk`

---

## 1. 一句话是什么

**横屏手动操作的肉鸽冒险**：选战士/法师/道士 → 分支地图推进 → 实时战斗清波次 → 用**五行相克**与**职业专武（属性+特效）**构筑强度 → 商店/掉落/果实补装 → 三章 Boss 通关。

类型关键词：`动作` · `肉鸽地图` · `三职业` · `五行克制` · `装备构筑` · `软萌手绘风 Canvas`

---

## 2. 整体流程

```
标题
 ├─ 继续冒险（本局存档）
 ├─ 开始新冒险 → 选职业 → 开场剧情 → 地图
 ├─ 操作说明
 └─ 记录 / 设置

地图
 ├─ 选路点（战斗/商店/金币/事件/休息…）
 ├─ 「装备」配置栏 · 「买装」行商 · 「用药」
 └─ 保存回标题 / 放弃本局

战斗 ARENA
 └─ 清场评价 S/A/B/C → 经验/金币/掉落 → 升级选天赋？ → 回地图

商店 / 装备栏 / 事件 / 升级 / 章节通关剧情 / 结算
```

**界面相位（`Screen`）**  
`TITLE` · `HOW_TO` · `SETTINGS` · `CLASS_SELECT` · `STORY` · `MAP` · `ARENA` · `SHOP` · `GEAR` · `EVENT` · `LEVEL_UP` · `STAGE_CLEAR` · `RESULT`

## 3. 职业系统

| 职业 | 定位 | 操作手感 | 基础倾向 |
|------|------|----------|----------|
| **战士** | 近战清场、承伤 | 斩击扇形、冲锋、盾、旋风、裂地 | 高血、近距 |
| **法师** | 远程爆发、控场 | 火球点燃、冰冻、链雷、炎爆、陨星 | 高蓝、远距 |
| **道士** | 续航、毒伤、阵法 | 三符回血、毒雾、回春、镇符、天师阵 | 均衡续航 |

### 技能解锁（每职业 5 技能）

| 等级 | 槽位 | 说明 |
|------|------|------|
| Lv1 | 普攻 BASIC | 开局可用 |
| Lv2 | S1 | 第一主动 |
| Lv3 | S2 | 第二主动 |
| Lv4 | S3 | 第三主动 |
| Lv5 | ULT 必杀 | 大招；另有必杀槽充能可解放 |

**战士**：斩击 / 冲锋 / 铁壁 / 旋风斩 / 裂地斩  
**法师**：火球 / 冰环（冻结） / 链雷 / 炎爆 / 陨星雨  
**道士**：三符 / 毒雾（DoT+易伤） / 回春 / 镇符 / 天师阵  

技能带**真实状态**：冻、毒、燃、弱、盾、缓等（`StatusType`）。

### 升级天赋（三选一）

锋刃(+攻%) · 体魄(+血%) · 疾步(+移速) · 会心(+暴击) · 迅捷(-CD) · 嗜血(吸血) · 灵泉(回蓝) · 坚甲(减伤) · 焦油(燃烧增强) · 财运(掉金)

经验曲线约：1～2 战升 Lv2，中段 Lv3～4，Boss 前可摸 Lv5。

## 4. 地图与关卡

### 节点类型

| 类型 | 含义 |
|------|------|
| START | 起点 |
| MOB | 普通战斗（多波） |
| ELITE | 精英高危 |
| BOSS | Boss 多波 |

| TRAP | 陷阱掉血 |
| EVENT | 抉择事件 |
| EXIT | 章末出口 → 下一章 |

### 三章结构

| 章 | 名 | 主题 |
|----|----|------|
| 1 | 果冻草原 | 教学向分叉；早市铁匠可早买装 |
| 2 | 哭泣矿道 | 矿洞支路、黑市、矿脉魔 |
| 3 | 空罐王城 | 终局城廓、双 Boss 感混编 |

- 战斗点配置 **关卡主五行**（金/木/水/火/土关）。  
- 地图标注：**关型 · 波数 · 荐X克Y**（如金关 → 荐火）。  
- **右侧小五行相克图**（箭头 = 克制）。  
- 顶部可随时 **装备 / 买装**。

### 第一章路径逻辑（摘要）

营地 → 史莱姆窝(木) → **金币袋 / 早市铁匠 / 黏液冲沟** → 混战原(水) → 篝火 / 流动铁匠 / 神秘商人 → … → 铁匠铺 → 支路战 → 精英 → **草原霸主(木 Boss)** → 出口。

金币与武器价位大致匹配：开局约 32 金；入门武约 28；精良 48～72；史诗 90～120。

## 5. 五行相克

循环（箭头为「克」）：

```
金 → 木 → 土 → 水 → 火 → 金
```

- 克制伤害约 **×1.42**（共鸣武器可再抬）  
- 被克约 **×0.72**  
- 武器与怪物身上显示五行字  
- 命中克制飘 **「克制!」**，被克飘 **「被克」**

> 注意：标准循环是 **火克金**（金关荐火），不是土克金。

## 6. 装备系统（v1.2 核心）

### 规则

- **职业专武**：仅对应职业可装备（错职会提示）。  
- **通用器**：三职业都能装，属性略逊专武。  
- 商店约 **70% 专武优先** + 下一关克制五行优先。  
- 掉落清场：**保底武器**；常掉果实；场上未捡自动吸入。

### 属性面板

| 属性 | 作用 |
|------|------|
| 攻 atkBonus | 面板攻击 |
| 暴击 crit | 额外暴击率 |
| 技伤 skillAmp | 技能倍率 |
| 吸血 lifeSteal | 伤害回血 |
| 冷却 cdr | 技能 CD 缩短 |
| 血/蓝 hpBonus mpBonus | 最大生命/法力 |
| 移速 spdBonus | 移动速度 |
| 减伤 drBonus | 受伤降低 |

另有防具锻造等级（商店升级）、武器「磨刀」小等级（篝火）。

### 特效 `GearProc`（战斗生效）

| 特效 | 效果概要 |
|------|----------|
| 燃刃 | 命中点燃 |
| 霜凝 | 几率冻结 |
| 毒浸 | 命中上毒 |
| 裂波 | 普攻/重击溅射周围 |
| 吸灵 | 命中回蓝 |
| 嗜血 | 额外吸血 |
| 杀意 | 击杀短暂护盾 |
| 处决 | 低血敌人加伤 |
| 共鸣 | 克制倍率提高 |
| 回春 | 治疗量提高（道士向） |
| 反震 | 受伤反弹 |
| 战意 | 命中叠层增伤感 |
| 连锁 | 重击弹射另一目标 |

### 职业装备倾向

| 职业 | 专武手感 |
|------|----------|
| 战士 | 溅射、吸血、处决、反震、战意 |
| 法师 | 技伤、燃/冻、连锁、吸灵、冷却 |
| 道士 | 毒、回春加强、杀意盾、吸灵续航 |

### 武器库规模（约）

- 起步 ×3（战/法/道）  
- 战士专武约 7  
- 法师专武约 7  
- 道士专武约 7  
- 通用约 5  

品质：普通 / 精良 / 史诗。  
完整列表与数值见代码：`LootSystem.kt` → `WeaponCatalog`。

### 装备配置 UI（地图「装备」）

- 当前武器：品质 · 职业 · 五行 · 属性一行 · 特效 · 风味文案  
- 可装列表：仅本职业 + 通用  
- 五行果实使用、用药  
- 商店内也可打开装备栏

## 7. 道具与掉落

### 战斗掉落（地上物）

| 种类 | 标识 | 说明 |
|------|------|------|
| 金币 | 黄点 | 击杀掉落 |
| 回血球 | 绿 | 概率 |
| 武器 | 橙「武」 | 提高概率；精英/Boss 额外 |
| 技能残卷 | 紫「卷」 | 永久技能强度 |
| 五行果实 | 果/属性字 | 消耗品入背包 |

清场：未捡物吸入 + **保底武器** + 高评价可能额外武器 + 常掉果实。

### 五行果实（消耗）

| 果实 | 效果 |
|------|------|
| 金之果 | 下一战武器视为金，攻+6 |
| 木之果 | 立即回血 28% |
| 水之果 | 立即回蓝 40% |
| 火之果 | 下一战攻击附带点燃 |
| 土之果 | 下一战受伤 -12% |

开局送 1 个木之果；商店可买。

### 残卷

入门 +8% / 精修 +12% / 奥义 +18% 技能伤害（可叠加进 `skillPowerBonus`）。

### 药水

地图/战斗可喝：约回 40% 最大生命；商店约 18 金。

## 8. 战斗系统（`ArenaSim`）

- 自写弹簧感演出 + AI，非 Box2D。  
- **多波次**，波间短间歇；威胁随章节/清房/节点类型上升。  
- AI：`CHASE` / `RANGED` / `CHARGER` / `BOSS`；精英加强、狂暴低血。  
- 部分怪有护甲、反伤刺。  
- **必杀槽** 0～100：击杀/连击充能，满可解放必杀。  
- **连击 / 狂热 / 清场评价 SABC** 影响奖励金与经验。  
- 操作：左摇杆移动；右技能键（普攻不位移瞬移）；暂停可保存回标题。  
- HUD：大血条蓝条、必杀条、当前武器与特效简称。

### 怪物一览

绿/粉/刺壳史莱姆 · 甲虫 · 夜蝠 · 骷髅 · 小哥布林 · 矿鼠 · 幽火 · Boss 草原霸主 · Boss 矿脉魔（各有独立可爱绘制）。

## 9. 商店

- 节点商店 + 地图 **「买装」行商** + 金币袋 **「收下并买装」**。  
- 货架：约 3 把武器（荐克制高亮）· 五行果实 · 残卷 · 药水 · 防具升级。  
- 左侧：已有可装武器一键装备。  
- 提示行：下一关关型与推荐五行。

## 12. 工程结构（主玩法包）

```
app/src/main/java/com/jellystorage/play/
├── PlayScreen.kt      # UI 相位、输入、地图/商店/装备/战斗绘制
├── ArenaSim.kt        # 战斗模拟、AI、技能、掉落、特效结算
├── ClassDefs.kt       # 职业、技能、天赋、地图节点与三章配置
├── LootSystem.kt      # 五行、武器目录、特效、残卷、果实
├── RunMeta.kt         # 单局状态、商店刷新、背包、推荐关型
├── ProgressStore.kt   # SharedPreferences 生涯 + 本局存档
├── StoryData.kt       # 剧情与事件文案
├── CharacterSkins.kt  # 职业/怪物可爱绘制、EnemyKind
└── BattleScene.kt     # 战场背景装饰
```

遗留/旁路：`softbody/*`、早期 engine 等仍在仓库，**当前产品路径以 `play/*` 为准**。  
说明类旧文档：`docs/GAME_BRIEF.md`（拼装自动战概念，已被现行玩法替代）。
